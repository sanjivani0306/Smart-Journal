### Smart Journal — AI-Powered Journaling & Mood Analytics
**React.js, FastAPI, PostgreSQL, Python, JWT, AI/LLM, Vercel, Render**

- Developed a full-stack AI-powered journaling platform that analyzes journal entries to extract **mood, sentiment, themes, behavioral patterns, and personalized reflections**.
- Built RESTful APIs using **FastAPI** with JWT-based authentication, PostgreSQL persistence, journal management, analytics, and AI-powered processing.
- Developed a responsive **React.js** frontend featuring a GitHub-style mood heatmap, analytics dashboards, AI Companion, journal timeline, and Music & Ambience experience.
- Implemented AI-driven **mood and theme extraction, pattern analysis, and personalized reflection generation** from historical journal entries.
- Integrated **Web Audio API-based ambient soundscapes** with mood-based recommendations, playback controls, volume management, and journaling session support.
- Deployed the React frontend on **Vercel** and FastAPI backend on **Render**, configuring production environment variables, CORS, API integration, and PostgreSQL connectivity.
