# Smart Journal Frontend — ZIP Style

This frontend is copied from the supplied Smart Journal & Mood Analytics ZIP style.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Important

This frontend intentionally uses the ZIP's `/api/...` endpoint contract. It is the UI layer only. Connect those endpoints to the FastAPI backend in the next step.

The old `Loading.jsx`, `Dashboard.jsx`, `MoodCalendar.jsx`, `MoodChart.jsx`, and `MoodBadge.jsx` structure is not used by this version.
